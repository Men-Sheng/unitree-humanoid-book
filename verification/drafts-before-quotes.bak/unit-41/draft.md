## A.2 单位与书写约定

一，**全程 SI**，但保留三处行业习惯：电池用 Ah 与 Wh、算力用 TOPS/TFLOPS、相机分辨率用像素。凡保留处，正文第一次出现时给出换算。

二，**N·m 不写成 J。** 扭矩与能量量纲相同但物理不同，混写会导致“扭矩 × 角度 = 能量”这类式子被误读。

三，**kg 是质量。** 涉及“体重”时本书仍写 kg，但凡是力都换算成 N（例：35 kg → 343 N）。本书曾因此犯过一次错（把力与质量直接相减），记录在 `bible/do-not-touch.md`。

四，**转速一律 rad/s。** 引用厂商 rpm 时保留原值并加括注。

五，**百分数与“倍”不混用。** “涨 58%” 与 “是原来的 1.58 倍” 二选一，同一句里不并存。

六，**数量级词表**：几十（20–90）、几百（100–900）、千级、万级。不用“若干”“一些”修饰可数的量。

## A.4 三个必须标明“口径”的量

这是本书最高频的错误来源。**任何一处出现这三个量，都必须写明口径，否则视为未完成。**

**一、扭矩常数 k_t**：输出端 or 转子端？判据见第 04 章（k_t × 峰值电流 ≈ 峰值扭矩 ⇒ 输出端）。

**二、扭矩**：峰值 or 额定？宇树全系只公布峰值 [未]。仿真模型里的 effort 是第三种东西（约束值），见第 02 章冲突表。

**三、频率**：总线通信频率、控制环路频率、PWM 载波频率是三件事。判据见第 12 章的带宽算术。

## A.5 变换约定声明

全书统一使用**幅值不变（amplitude-invariant）Clarke/Park 变换**：

```text
i_α = (2/3)(i_a − ½i_b − ½i_c)
i_β = (2/3)(√3/2)(i_b − i_c)

⇒ 三相对称正弦时 |(i_α, i_β)| = 相电流峰值
⇒ 扭矩式 τ = (3/2)·p·λ_m·i_q，系数为 3/2
```

若读者参考的资料使用功率不变变换（系数 √(2/3)），则其扭矩式系数为 3/2 或 √3/2 不等，**系数不同不代表有人算错，只代表约定不同**。判据：**同一份资料里，变换系数与扭矩系数必须成对出现**（第 07、10 章各给了一次自检）。

## A.6 术语对照（一词一义表）

本书严格区分下列常被混用的词。

| 本书用法 | 不用它指 | 易混词 |
|---|---|---|
| 人形 / 双足 | 四足、轮式 | “机器人”（本书凡说“机器人”指全类） |
| 关节 | 电机、执行器 | 三者层次不同：电机 ⊂ 关节  执行器系统 |
| 电机 | 关节模组 | 模组 = 电机 + 减速器 + 编码器 + 驱动板 |
| 减速比 N | 传动效率 | 效率写 η |
| 齿隙 | 回差、背隙（同义，首次出现时并列给出） | 与“弹性变形”区分：齿隙是空程，弹性是可恢复形变 |
| 刚度 kp | 硬度、强度 | 硬度是材料属性，强度是失效界限 |
| 柔顺 / 顺从 | 软（口语） | 统一写“低刚度” |
| 扭矩密度 | 功率密度 | 前者 N·m/kg，后者 W/kg |
| 额定 | 持续 | 本书用“额定（持续）”，首次出现处并列 |
| 峰值 | 最大 | 统一写“峰值”，并注明是角点值 |
| 强化学习 | RL 策略、神经网络控制 | 统一写“强化学习（RL）” |
| 模仿学习 | 行为克隆（是其最简形式） | 首次出现处说明包含关系 |
| 世界模型 | VLA、动作专家 | 四用法见第 34 章，禁止混用 |
| 策略 | 模型、网络 | “策略”专指 观测→动作 的映射 |
| 本体感知 | 传感器（泛称） | 专指关节与 IMU 类自身状态测量 |
| 仿真 | 数字孪生 | 本书不用“数字孪生” |
| 落地（部署义） | 落地（触地义） | 触地一律写“触地”或“足端触地”，部署一律写“部署” |
| 实时 | 快 | 实时 = 最坏情况有界，不是平均快 |
| 确定性 | 稳定 | 确定性 = 时间有界；稳定 = 不发散 |
