# 转子不介意你是斩波的：两级低通与“平均”为什么合法

> 状态：初稿 v1（2026-10-08）。本章回答读者从第 08 章一定会带出来的质疑。

## 一秒钟两万次的通断，凭什么电机不抖

第 08 章说：改变导通时间就能合成任意大小的平均电压。

任何做过数字电路的人第一反应都是怀疑：**那我的电机不是每 50 微秒被踹一脚吗？** 20 kHz 的通断，一秒钟两万次。而转子是一个有质量的物体。它凭什么不抖？

答案是：它确实被踹了两万次，但**踹它的能量几乎全部被两级积分器吸收了**。这两级积分器一个是铜和铁做的，一个是钢和铝做的。这一章把这两级算出来。

## 第一级：电感是一个电流积分器

第 08 章已经用了这条式子，现在把它当主角看：

```text
V = L · di/dt        ⇔        i(t) = i(0) + (1/L)∫V dt
```

请注意右边那个积分号。**电流是电压的时间积分。** 这意味着：

- 你给一个 50 µs 的 24 V 脉冲，电流只涨 `24 × 50e-6 / L`；
- 你要在**一个开关周期内**让电流跑完它最终要到的值，需要 L 无穷小；
- L 越小、周期越长，电流波形越接近“跟着电压走”；反之越接近“跟着电压的平均值走”。

定义一个时间常数：

```text
τ_e = L / R
```

这是这个 RL 回路自己的节奏。只有当开关周期 T **远小于** τ_e 时，电流才来不及跟上瞬时电压，只能跟上平均值。工程判据是：

```text
T ≤ τ_e / 10        ⇒ 电流纹波占平均值的比例 ≲ 10%

**这条 1/10 不是行规，是两行代数。** 半桥驱动一个 RL 加反电势的负载，一个开关周期里只有两种接法：
上管导通时绕组两端电压是 V_bus，下管导通时绕组自己续流、两端电压是 0。设占空比 d、周期 T，稳态下
反电势 E = d·V_bus，平均电流 I = E/R。

```text
导通期电流上升：Δi = (V_bus − E)·(dT)/L = V_bus·(1−d)·d·T/L
纹波峰峰值：    Δi_pp = V_bus · d(1−d) · T ÷ L
相对平均值：    Δi_pp ÷ I = (1−d)·T·R ÷ L = (1−d)·T ÷ τ_e
```

三件事一次说清了。**纹波最大的位置是 d = 0.5**（因为 d(1−d) 在那里取极值，本章上面说的就是它）；
**相对误差的上界是 T ÷ τ_e**（d 趋 0 时取到，因为那时 (1−d) ≈ 1）；
所以要让纹波在任何占空比下都不超过平均电流的 10%，就必须 **T ≤ τ_e ÷ 10**——
这条判据的全部内容就是"最坏那一格也不超过 10%"，不是什么行业默契。

*（顺带解释了一个常见误解：纹波电压摆幅与相对纹波不是一回事。绝对纹波在 d = 0.5 最大，
相对纹波却在 d 小的高速轻载区最大。工程上真正疼的是前者——它决定损耗和噪声；
判据里用的却是后者，因为它决定"平均"这个说法成不成立。）*

```

（这是本书给的一阶判据 [算]，不是任何厂商的规格。）

纹波本身可以算出来：

```text
Δi ≈ V · d(1−d) / (L · f_sw)
```

**它在 d = 0.5 时最大**（因为 d(1−d) 在 0.5 取极值）。这条有个立刻可用的推论：**你的电流最脏的时刻，是输出电压用了一半母线电压的时候**，也就是转速跑到一半附近。

现在看第 08 章那个结论的另一面。M8010 反电势幅值在 30 rad/s 时是 12.78 V（第 08 章按幅值不变约定算的那个数），母线 24 V，所以正常工况下占空比就在 12.78 ÷ 24 ≈ 0.53 附近——\*\*几乎正压在 d = 0.5 那个纹波最大的点上\*\*。也就是说这颗电机在标称最高速附近运行时，恰好落在纹波较大的区间里。

（L 与 R 官方未公布 [未]，所以本书不能算出 Δi 的绝对值。但“d=0.5 附近最脏”这条与 L 无关，任何一台电机都成立。）

**关键的一点：纹波不产生平均扭矩。** 扭矩由 i_q 的**平均值**决定（第 04、05 章）。纹波只是在铜里发热、在铁芯里产生附加损耗、在声学上产生噪声。所以“提高开关频率让纹波变小”改善的是发热与噪声，**不是扭矩精度**。扭矩精度靠的是死区补偿与采样时刻（第 13 章）。

## 第二级：惯量是一个转速积分器

同样的逻辑再往下走一层。

```text
τ = J · dω/dt        ⇔        ω(t) = ω(0) + (1/J)∫τ dt
```

**转速是扭矩的时间积分。** 转子（连同减速器、连杆、负载折算到轴上的部分）有一个转动惯量 J，它让转速不可能在 50 微秒里改变多少。

定义机械时间常数（把扭矩与转速用 k_t、k_e 连起来，忽略阻尼）：

```text
τ_m = J · R / k_t²
```

（这是“给一个电压阶跃、转速到达稳态 63% 要多久”的一阶近似 [行]。）

代一个量级看看。M8010 转子侧 k_t = 0.10094 N·m/A。若转子侧惯量在 1e-5 kg·m² 量级（**这是本书假设的量级，官方未公布** [未]），R 在 0.05 Ω 量级（同样 [未]）：

```text
τ_m ≈ 1e-5 × 0.05 / 0.10094² = 4.9 ms
```

**5 毫秒。** 而开关周期是 0.05 毫秒。**相差 100 倍。** 转子对开关这件事的“感觉”，就像一艘万吨轮对浪花的感觉。

两级加起来，这台电机的响应结构是：

```text
开关（0.05 ms）→ 电感积分（τ_e 零点几 ms）→ 电流
                → 惯量积分（τ_m 几 ms）→ 转速
                                    → 再积分 → 角度（几十 ms 起）
```

**每一级都是一个积分器，每一级都比上一级慢 10–100 倍。两级串联，就把 20 kHz 的方波抹成了一个几乎平滑的转速。** 这就是“平均”合法的完整理由——不是近似技巧，是这台机器本身的物理结构。

## 那频率为什么不能无限高

因为第二笔账会来收钱。

```text
开关损耗 P_sw ≈ ½ · V · I · (t_rise + t_fall) · f_sw      ← 正比于 f_sw
导通损耗 P_on = I² · R_ds(on)                              ← 与 f_sw 无关
```

**提高 f_sw 让纹波变小（∝ 1/f_sw），但让开关损耗线性变大。** 两条曲线一交，就有一个最优点。这个点具体在哪，取决于器件的 t_r + t_f、母线电压、电流、以及你能带走多少热（第 36 章）。

机器人关节选 20 kHz 左右（行业常见量级 [行]；**宇树未公布任何一款关节的载波频率** [未]），除了电气考虑，还有一个非常不“物理”但非常真实的原因：

**20 kHz 刚好在人耳听觉上限之外。**

10 kHz 以下的 PWM 会让电机发出清晰的啸叫。一台 23 个关节的人形在安静的办公室里以 10 kHz 开关，听起来像一墙老式 CRT 显示器。这不是性能问题，是产品问题——但它是那种**会在评审会上被提出来、并且必须改的问题**。所以“为什么是 20 kHz 而不是 8 kHz”这个问题，一半答案是电气的，一半答案是市场部的。

## 一个立刻能用的推论：你能控制的最快的事，就是电流

两级低通还给出一个反向结论，它是第 12 章级联结构的地基：

**积分器不能对被积的东西做快的反应。** 电流环能跑 1–2 kHz，因为 τ_e 是零点几毫秒；速度环只能跑几百赫兹，因为 τ_m 是几毫秒；位置环只能跑几十赫兹，因为连杆与负载更大。

所以当你想“让关节反应更快”，唯一有效的方向是**让电流变化更快**——提高 f_sw、减小 L（但 L 小纹波大）、提高母线电压（但器件耐压与绝缘要跟上）。**没有任何算法能让你绕过 τ_m。** 这条判据能帮你在选型会上省掉很多废话。

## 类比，以及它在哪儿破

类比：用一把脉冲式水枪推一辆水车。你每秒扣两千次扳机，水车只觉得有一股稳定的力在推它——因为水车的转动惯量把每一次冲击都摊平了。

**这个类比在哪里破两处**。第一，水车的阻力矩与转速无关，而电机的反电势**正比于转速**——所以“水车越转越难推”这件事在电机里是真实存在的，而且是第 08 章那个电压包络的全部来源。第二，水枪的脉冲不会让水车发出声音，而 PWM 会让电机啸叫——机械结构不但不完美积分，还会把某些频率放大（那就是第 22 章的结构模态）。

---

**一个可检验的说法**：PWM 斩波之所以不引起机械振动，是因为电流对电压、转速对扭矩构成两级串联积分器，其时间常数分别约为 τ_e = L/R（零点几毫秒量级）与 τ_m = J·R/k_t²（几毫秒量级），都比开关周期慢 10–100 倍；因此任何“让关节反应更快”的需求只能从电流环往上解决，不可能通过算法绕过 τ_m。

**证据等级**：V = L·di/dt、τ = J·dω/dt、两级积分结构、纹波公式、开关损耗正比于频率，全部是电路与控制通识 [行]；τ_m ≈ 4.9 ms 是 [算]，但**输入 J 与 R 是本书假设的量级，官方未公布** [未]，所以这个数只能当“数量级感觉”用，不能当 M8010 的参数引用；20 kHz 是行业量级 [行]，宇树未公布 [未]；“d = 0.5 时纹波最大”与“反电势 12.78 V ⇒ 正常工况 d ≈ 0.53”是 [算]。

**可核对清单**：

- [ ] 自己代一次 τ_m：拿你手边任何一颗电机的 J、R、k_t，看是不是毫秒级
- [ ] 用 Δi ∝ 1/f_sw 与 P_sw ∝ f_sw 画两条线，标出它们的交点，那就是你能选的最高频率
- [ ] 找一段 8–12 kHz 的 BLDC 驱动音频（开源社区有），亲耳听一下“为什么是 20 kHz”
