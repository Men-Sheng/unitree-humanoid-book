## 自绘图的生成方式（供校对与复现）

全部自绘图是**手写 SVG**，源文件 `assets/fig/*.svg`，由两个脚本生成：
`python tools/make_figs.py`（第 0–2 部 13 幅）、`python tools/make_figs.py && python tools/make_figs2.py`（第 3–5 部 16 幅）。图片包光栅化：`cd print && node rasterize.mjs`。

为什么不用 matplotlib 出 PNG：这些是示意图，SVG 里的文字是文本节点，由排版引擎用正文同一款 Noto Serif SC / Noto Sans SC 渲染，不会出现图内字体与正文不一致，也不引入第二套字体子集。
