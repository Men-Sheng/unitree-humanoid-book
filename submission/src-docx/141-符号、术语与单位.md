## A.2 单位与书写约定

一，**全程 SI**，但保留三处行业习惯：电池用 Ah 与 Wh、算力用 TOPS/TFLOPS、相机分辨率用像素。凡保留处，正文第一次出现时给出换算。

二，**N·m 不写成 J。** 扭矩与能量量纲相同但物理不同，混写会导致“扭矩 × 角度 = 能量”这类式子被误读。

三，**kg 是质量。** 涉及“体重”时本书仍写 kg，但凡是力都换算成 N（例：35 kg → 343 N）。本书曾因此犯过一次错（把力与质量直接相减），记录在 `bible/do-not-touch.md`。

四，**转速一律 rad/s。** 引用厂商 rpm 时保留原值并加括注。

五，**百分数与“倍”不混用。** “涨 58%” 与 “是原来的 1.58 倍” 二选一，同一句里不并存。

六，**数量级词表**：几十（20–90）、几百（100–900）、千级、万级。不用“若干”“一些”修饰可数的量。

## A.4 三个必须标明“口径”的量

这是本书最高频的错误来源。**任何一处出现这三个量，都必须写明口径，否则视为未完成。**

**一、扭矩常数 k_t**：输出端 or 转子端？判据见第 04 章（k_t × 峰值电流 ≈ 峰值扭矩 ⇒ 输出端）。

**二、扭矩**：峰值 or 额定？宇树全系只公布峰值 [未]。仿真模型里的 effort 是第三种东西（约束值），见第 02 章冲突表。

**三、频率**：总线通信频率、控制环路频率、PWM 载波频率是三件事。判据见第 12 章的带宽算术。

## A.5 变换约定声明

全书统一使用**幅值不变（amplitude-invariant）Clarke/Park 变换**：

```text
i_α = (2/3)(i_a − ½i_b − ½i_c)
i_β = (2/3)(√3/2)(i_b − i_c)

⇒ 三相对称正弦时 |(i_α, i_β)| = 相电流峰值
⇒ 扭矩式 τ = (3/2)·p·λ_m·i_q，系数为 3/2
```

若读者参考的资料使用功率不变变换（系数 √(2/3)），则其扭矩式系数为 3/2 或 √3/2 不等，**系数不同不代表有人算错，只代表约定不同**。判据：**同一份资料里，变换系数与扭矩系数必须成对出现**（第 07、10 章各给了一次自检）。

## A.6 术语对照（一词一义表）

本书严格区分下列常被混用的词。

| 本书用法 | 不用它指 | 易混词 |
|---|---|---|
| 人形 / 双足 | 四足、轮式 | “机器人”（本书凡说“机器人”指全类） |
| 关节 | 电机、执行器 | 三者层次不同：电机 ⊂ 执行器 ⊂ 关节 |
| 电机 | 关节模组 | 模组 = 电机 + 减速器 + 编码器 + 驱动板 |
| 减速比 N | 传动效率 | 效率写 η |

| 刚度 kp | 硬度、强度 | 硬度是材料属性，强度是失效界限 |

| 强化学习 | RL 策略、神经网络控制 | 统一写“强化学习（RL）” |

## A.7 引用与标注

**七级来源标记**：[厂] 官方页面或官方仓库文件；[拆] 第三方拆解、券商研报、逆向工程；[行] 教科书与行业通识（**不是宇树事实**）；[算] 本书推算（附录 B 有脚本）；[未] 查不到。另用 [查] 表示“来自可链接的公开资料（论文、文档、报道），本书已读到原文但未独立复现”。另用 [推] 表示**本书自己的推断，没有一手来源支撑**——凡用它处都明写这是推断，不许把它当成已核实的事实；与第 00 章图例的七个标记一一对应。

**引用格式**：正文用上标式标记，出处集中在附录 E，逐条给 URL 与抓取日期。

**语录块**：每章一段王兴兴语录，格式固定为“引文 —— 出处（媒体/书名）— 日期（类型：问答实录/演讲/书面）”。**引号内必须是逐字引文**；若只找到转述，本书写“大意，非逐字引文”并单独标注（这一条来自一次实际犯错，见 `bible/do-not-touch.md` 第 34 条）。

**这条规则的实际达成度**：41 个正文章里 **41 章**有题引，**0 章留空**——其中 32 章是王兴兴本人（逐字可回读），9 章按作者的决定改用埃隆·马斯克的公开言论。
改用马斯克的是第 05、07、09、10、11、12、18、24、28 这九章——磁场的垂直分量、三相旋转磁场与谐波、斩波与“平均”为什么合法、Clarke 与 Park、i_q 管扭矩 i_d 管磁场、三个环的带宽递减律、刚度由三道天花板决定、IMU 与状态估计、中间件与“去 ROS 化”。
换人的原因和留空的原因是同一件事：检索过问答实录、演讲与书面访谈三类材料，王兴兴本人在这些主题上**没有留下可回读的逐字技术表述**——他谈的是路线与成本判断，不是磁场定向、坐标变换、死区或零偏。硬套只会得到一句不属于该章的话。
**说话人变了，本书就把它写在明处**：这九块的出处行带 `speaker` 字段，排印时说话人显示为马斯克，不冒充王兴兴。来源层级也分两档——其中 2 条出自特斯拉自己发布的股东更新 PDF（本书用 PyMuPDF 抽全文逐字核对，记 [查]）；另外 7 条是第三方报道里的逐字引句，**本书未核对录音或视频原文**，出处行的 `类型` 里明写这一点。愿景类的话（“史上最大产品”“手术级”）不参数、不当规格用，这一点与王兴兴那 32 条同规矩。

其中 **5 条**（第 17、19、20、27、37 章）是演讲整理稿、书面化微调或记者转述，本书在出处行的
`类型` 里明写，不冒充逐字。

**法律口径**：语录引用依《著作权法》第 24 条适当引用；本书不引用任何未公开信息；不对上市公司做业绩判断；全书不构成采购或投资建议。


## A.8 图的达成度（和 A.7 同一条规矩：缺就写明）

图台账 `bible/images.md` 计划 **36 幅**，本印本里是 **33 幅**，全部为本书自绘的 SVG——推导图、结构图、时序与账目图。差的 3 幅不是“还没画”，而是**只有作者本人能提供**：需要一台真机与一颗可以拆开摆平的样机。它们是

**为什么不用厂商的图**：出版社必须能证明版权。新闻页上的照片与视频是对方的资产，本书按“**官方素材 0 张**”处理。代价就是这三格——“真机长什么样”这件事，除了拍没有第二种来路。三处在台账里各带一条 `status: 待拍`；交稿时应连同这份台账一起给编辑，让空槽是**登记过的空槽**，而不是漏掉的图。

**这也顺带说明本书的图在讲什么**：33 幅自绘图里没有一张是装饰。每一幅都对应正文里一条能按计算的式子或一条口径声明，图上标的每个数都能在同一个文件的正文里找到出处；找不到出处的那一类（例如“某关节内部到底几级减速”），本书画成问号而不是画成曲线。
