## 讲什么

**以在售的宇树人形机器人为唯一解剖对象，从"上层想要 60°"一路挖到"一颗 MOSFET 在 50 µs 内关断"，
每一跳都给出读者能自己复算的数。**

| 维度 | 覆盖 |
|---|---|
| 机型 | H1 / H1-2、G1（含 EDU）、R1、H2、Dex1/Dex2/Dex3-1/Dex5-1 手、Z1 臂（作为人形的作业臂）、Unilidar L1/L2 |
| 器件来源 | 关节电机（GO-M8010-6、IM6014 等）、行星与谐波减速器、双编码器、FOC 驱动板、MOSFET 与栅极驱动、母线电容、电流采样、电池与 BMS、IMU、深度相机、激光雷达、SoC 算力档、RS-485 / CAN-FD / EtherCAT、抱闸与急停 |
| 原理层（本书的主菜） | 洛伦兹力与 τ = m × B、换向与三相旋转磁场、PWM 伏秒平衡与六边形、Clarke/Park、i_q 与 i_d、MTPA 与弱磁、两级低通时间常数、死区与采样时刻、编码器分辨率与齿隙、准直驱、倒立摆与 ZMP 与捕获点、阻抗控制的 ω_n 上限、MPC、sim2real、状态估计与融合、内存墙与延迟墙、动作分块、复合衰减、热阻链、平方-立方律 |
| 整机层 | 一颗关节 → 一条腿 → 一个姿态 → 一双眼睛 → 一个大脑 → 一天的续航与安全 |
| 方法层 | 每章"往下挖"四问（栈 / 机制 / 底座 / 边界）+ 全书可复算脚本（附录 B） |

四足（Go2/Go1/A1/B2/AS2）**只承担两件事**：① 关节器件的史料（GO-M8010-6 从 Go1 时代开始卖、
IM6014 早期装在四足上）；② "四个支点可以零力矩、两个支点全程不行"的能量与控制对照。
除这两处外不许新增四足内容，型号名只允许出现在附录 C 的器件来源表里。

## 故意不讲（以及为什么）

| 不讲 | 原因 | 去哪 |
|---|---|---|
| 可复制的完整工程代码（驱动一个电机的 C 代码、部署脚本） | 那是另一种书；本书 `real` 代码为零，只给伪流程与判据 | 归档大纲 `outline/archive-units-developer-manual.yaml`；附录 D 给路标 |
| 刷固件、解锁低层权限、绕过保修的操作步骤 | 高风险，且作者本人操作真机，不该由书替他承担后果 | 只讲"谁被挡在哪一级、为什么"（第 28、39 章） |
| 硬件维修、结构改装、自制整机 BOM | 需要厂商授权与安全责任 | 不讲；第 40 章给"最小可行系统"的判据 |
| 机型导购、性价比结论 | 会立刻过期，且不是"讲原理" | 价格只作为数量级锚点出现，一律带日期与来源标记 |
| 企业传记、创始人故事、融资史 | 读者要的是"机器怎么回事" | 第 02 章只讲产品线为什么这么排；语录块只放技术判断 |
| 具身智能的哲学与未来学（意识、统治人类、就业末日） | 不可检验，且是本书要拆的营销词 | 第 32、34、39 章只谈可核对的事实与许可 |
| 电机本体的电磁设计（槽极配合、绕组匝数怎么算、磁钢结构） | 挖到"器件参数决定扭矩常数"就停，再往下是电机厂的专业纵深，且宇树不公布 | 第 05、11 章给 k_t 与 λ_m 的位置与量级；附录 D 指向电机设计教材 |
| 人形整机厂商的未公开内部工艺（良率、装配节拍、供应链账期） | 查不到，宁缺不假 | 附录 E 的「查不到」清单 |

## 深度政策（v3）

- **读者**：有软件/电子/机械/算法任一领域从业经验、没做过机器人的工程师与科技爱好者。
  不解释"什么是电压"，但必须解释"这颗关节的电压为什么够/不够"。
- **每章四问**：`stack`（这一层是什么）→ `mechanism`（靠什么实现）→ `base`（那这个又靠什么，
  直到物理定律/器件参数/信息论界限）→ `boundary`（这条链在哪里断、代价是什么）。
- **每章至少一条公式 + 一个读者能自己复算的数**；`[算]` 的数必须能在 `code/tools/` 的脚本里跑出来。
- 新术语预算每章 6 个，首次出现必须给一句话解释或指向"第 NN 章"。
- 幽默降为次要：前半段（第 0–2 部）不许变水。
- 冲突不抹平：官方口径与拆解口径不一致时两条都列，写明"本书取严的那条"或"两条并列待复验"。
