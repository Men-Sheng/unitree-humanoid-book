# bible/scope.md — 范围（完整版）

## 讲什么

**用真实在售的宇树全系列机型当解剖对象，讲清机器人由哪些器件组成、每个器件决定整机哪个指标、以及怎么用四道算术判断一台机器人行不行。**

| 维度 | 覆盖 |
|---|---|
| 机型 | Go2(AIR/PRO/EDU)、Go1、A1、B2/B2W、AS2、G1、H1/H1_2、H2、Z1、Dex1/Dex3、Unilidar L1/L2 |
| 器件层 | 关节电机、减速器、编码器、驱动板、电池与 BMS、IMU、深度相机、激光雷达、SoC 与算力档、总线与图传、结构件与材料、足端与防护 |
| 原理层 | 平衡与倒立摆、扭矩链、能量链（COT）、控制频率与延迟预算、支撑多边形与步态、平方-立方律、强化学习与模仿学习在算什么 |
| 整机层 | 同一套物理在不同机型上的取舍；一台机器狗的一天；价格与降价的技术原因 |
| 方法层 | 四道算术 + "别被这些词唬住"清单：读者拿去能判断**任何**一台机器人 |

## 故意不讲（以及为什么）

| 不讲 | 原因 | 去哪 |
|---|---|---|
| 控制理论推导（ZMP、模型预测、动力学方程求解） | 会立刻把科普读者甩下车，且已有成熟教材 | 第 14-21 章只给结论与可算的量级；推导指向机工社《四足机器人控制算法》 |
| SDK 用法、API、可复制工程代码 | 那是另一种书；本书 `real` 代码为零 | 归档大纲 `outline/archive-units-developer-manual.yaml`；附录 D 给路标 |
| 刷固件、解锁低层权限、越权操作 | 高风险且可能违反保修与合规 | 只讲"谁被挡在哪一级、为什么"（第 25、33 章） |
| 硬件维修、结构改装、BOM 与自制整机 | 需要厂商授权与安全责任 | 不讲；第 36 章只给"最小可行系统"的路标与判据 |
| 机型导购、价格对比与性价比结论 | 会立刻过期，且不是"讲原理" | 价格只作为**数量级锚点**出现，一律带日期 |
| 企业传记、创始人故事、融资史 | 读者要的是"机器怎么回事" | 第 03 章只讲"为什么变便宜"，不讲故事 |
| 具身智能的哲学与未来学（意识、统治人类、就业末日） | 不可检验，且是本书要拆的营销词 | 第 24 章拆词；第 38 章只谈可核对的真实落地场景 |
| 场效应管、FOC 环路推导、电机设计 | 超出"手能摸到、数能算出"的深度边界 | 第 4 部给入口 |

## 深度政策

- 第 0-3 部：科普深度。**先现象后命名**，每章新术语 ≤3，每个数字配日常锚。
- 第 4 部：给技术爱好者的深度，**仍然零工程代码**，只给伪流程与"该去看什么"。
- 附录：reference 深度，完整表格，每格带来源标记与日期。
- 层间不许互串：现象章不塞公式，公式章不塞情怀。

## 完成的定义（DoD）

1. 整书门禁 MG-1~MG-6 verdict = PASS；
2. **四道算术全部由 `arithmetic_check.py` 复算通过，且 `WARN` 全部消解或已写进正文**（带着差异写，不抹平）；
3. 附录 A 每个规格格要么有 [厂]/[拆]/[算] 来源，要么留空并明说"未公布"；
4. 每章至少一张自有图（作者实拍或自绘），或明确标注引用来源与许可；
5. 每章的每个类比都填了 `analogy_breaks_at`；
6. 附录 E《哪些是量过的、哪些是厂商说的、哪些没验证》与正文逐条对得上；
7. 三个形态（连载站 / PDF / EPUB）由同一份 `final/*.md` 构建成功并逐页目视核对。
