# bible/images.md — 图片政策与图片来源账

> 一句话：**这本书的图 95% 必须自产。** 宇树官方素材一幅都不能用。
> 全部事实与链接见 `research/image-rights-and-print-specs.md`；硬结论已抄进 `bible/do-not-touch.md` 第 25-30 条。

## 1. 三条腿，各占多少

| 来源 | 占比 | 许可 | 谁负责 |
|---|---|---|---|
| **作者真机自拍** | ≈50% | 作者自有，可授权出版社 | 作者（任务单：`outline/figures.yaml` 里 `owner: 作者`） |
| **本书自绘**（剖切图、爆炸图、架构图、推导图、数据图） | ≈45% | 本书创作，CC BY-SA 或随书授权 | 我出 SVG/脚本，作者审 |
| **公版 / CC 可商用引用** | ≤6 幅（≈5%） | PD、CC0、CC BY 4.0、CC BY-SA 4.0 | 逐幅登记（见 §3） |
| **宇树官方素材** | **0 幅** | 无授权 | 禁止 |

## 2. 四条禁止（出版社三审最容易在这里出事）

1. **不用宇树官网/商城/文档站/B站/公众号的任何图片。** 全站页脚只有"版权所有 © 2016-2025 宇树科技"，没有 press kit、没有媒体授权条款；`/terms` 只有 EULA 与售后。按《著作权法》第 29 条，未明确许可的权利不得行使。`oss-global-cdn.unitree.com` 上的图**能下载不等于能用**。
2. **不用 OpenStax、MIT OCW 的图。** 两者都是 **CC BY-NC-SA 4.0**，条款原文 "Noncommercial — You may not use the material for commercial purposes"。这是最容易被"它是开放教材啊"糊弄过去的一类。
3. **不用 GitHub 仓库里没有 LICENSE 文件的图。** 官方组织里无 LICENSE 的仓库是 **10 个**，其中包括 `unitree_rl_lab`——它 README 挂着 Apache-2.0 徽章但**没有 LICENSE 文件**。**徽章不等于授权。**
4. **不做"装饰性引用"。** 《著作权法》第 24 条第（二）项的"适当引用"要求引用是为介绍、评论或说明**该作品本身**；第（六）项的图书馆陈列等情形明文"不得出版发行"；第 25 条教科书法定许可对科普书不适用。**"这张图正好说明我讲的东西"不构成免授权理由。**

## 4. 自拍规格（作者任务单的技术底线）

| 用途 | 画幅 | 最低像素 | 说明 |
|---|---|---|---|
| 通栏图（跨整个版心） | 4:3 或 3:2 横构图 | **≥2008 px @300 dpi** | 版心宽约 110 mm，300 dpi 折算 |
| 半栏图 | 同上，裁方 | ≥1004 px | |
| 部件特写（电机、齿轮、脚垫） | 1:1 | ≥800 px | 留 20% 边距给标注线 |
| 爆炸图底图 | 横构图 | ≥2008 px | 干净背景，后期要抠图 |

通用要求：白天自然光、同一台机器、同一背景、**横构图**、四周留 20% 空白（给箭头和标号）、RAW 或最高质量 JPEG 原图保留（交稿时可能要 TIF）。
**不要自己转 CMYK、不要自己加出血**——那是印厂环节，两家出版社的作者须知都没有要求作者做。

## 5. 自绘五类（我出图，作者审）

| 类型 | 幅数 | 画法 | 工具 | 交付格式 |
|---|---|---|---|---|
| 架构图（六件事总图、三级控制、数据管线） | 5 | 方框 + 箭头 + 一句话说明，**不画立体效果** | SVG / draw.io | SVG + PDF 矢量 |
| 剖切/爆炸图（关节三件套、减速器三种方案） | 6 | 编号引线 + 图下表格 | SVG（基于作者实拍底图） | SVG + 300 dpi TIF |
| 推导图（倒立摆、支撑多边形、平方-立方律、延迟链） | 7 | 每图只讲一步，配一个数 | Python matplotlib | PDF 矢量 + PNG 600 px |
| 数据图（CoT 对比、价格曲线、频率分层） | 5 | 柱/散点，**轴上标来源类型** | matplotlib | PDF 矢量 |
| 时序图（感知→决策→执行） | 3 | 时间轴 + 各环节耗时 | Mermaid → SVG | SVG |

⚠ 自绘图里**文字要转曲**（outline paths）或用思源字体并保留源文件，否则交稿时容易混进工具默认的方正字体而需要授权。

## 6. 每幅图必须登记的字段（`outline/figures.yaml`）

```yaml
- unit: "05"            # 哪一章
  id: F-05-2            # 图号（正文用"图 05-2"）
  caption: "一只关节电机：转子侧 3.7 牛米，输出侧 23.7 牛米"
  kind: 自拍 | 自绘 | 引用
  owner: 作者 | 本书 | 第三方
  license: 自有 | CC0 | CC BY 4.0 | 公有领域 | 待授权
  source_url: ""        # 引用类必填
  attribution: ""        # 图注里必须出现的署名文字
  status: 待拍 | 待绘 | 已完成 | 已授权
  spec: 通栏 ≥2008px
```
**没有 license 字段的图不许进 `final/`。** 这条由 `tools/build_book.py` 执行：缺图或状态未完成的，在 PDF 里留一行 HTML 注释而不是硬塞图。

## 7. 交稿时的图片声明（模板，出版社要）

> 本书插图共 N 幅，其中作者自拍 X 幅、本书绘制 Y 幅、引用第三方 Z 幅。引用图片的著作权归各自所有者，均已按各自许可要求在图注中标明作者与来源；作者保证对其余图片拥有完整著作权，并已就引用部分取得必要许可。

（机工社的须知把图片侵权责任完全压给作者，所以这份声明 + 逐幅登记表是保护自己的唯一手段，不是形式主义。）
