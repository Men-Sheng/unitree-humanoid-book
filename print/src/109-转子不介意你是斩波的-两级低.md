# 转子不介意你是斩波的：两级低通与"平均"为什么合法

## 一秒钟两万次的通断，凭什么电机不抖

第 08 章说：改变导通时间就能合成任意大小的平均电压。

任何做过数字电路的人第一反应都是怀疑：**那我的电机不是每 50 微秒被踹一脚吗？** 20 kHz 的通断，一秒钟两万次。而转子是一个有质量的物体。它凭什么不抖？

答案是：它确实被踹了两万次，但**踹它的能量几乎全部被两级积分器吸收了**。这两级积分器一个是铜和铁做的，一个是钢和铝做的。这一章把这两级算出来。

## 第一级：电感是一个电流积分器

第 08 章已经用了这条式子，现在把它当主角看：

```text
V = L · di/dt        ⇔        i(t) = i(0) + (1/L)∫V dt
```

请注意右边那个积分号。**电流是电压的时间积分。** 这意味着：

- 你给一个 50 µs 的 24 V 脉冲，电流只涨 `24 × 50e-6 / L`；
- 你要在**一个开关周期内**让电流跑完它最终要到的值，需要 L 无穷小；
- L 越小、周期越长，电流波形越接近“跟着电压走”；反之越接近“跟着电压的平均值走”。

定义一个时间常数：

```text
τ_e = L / R
```

这是这个 RL 回路自己的节奏。只有当开关周期 T **远小于** τ_e 时，电流才来不及跟上瞬时电压，只能跟上平均值。工程判据是：

```text
T ≤ τ_e / 10        ⇒ 电流纹波占平均值的比例 ≲ 10%
```

**这条 1/10 不是行规，是两行代数。** 半桥驱动一个 RL 加反电势的负载，一个开关周期里只有两种接法：
上管导通时绕组两端电压是 V_bus，下管导通时绕组自己续流、两端电压是 0。设占空比 d、周期 T，稳态下
反电势 E = d·V_bus，平均电流 I = E/R。

```text
导通期电流上升：Δi = (V_bus − E)·(dT)/L = V_bus·(1−d)·d·T/L
纹波峰峰值：    Δi_pp = V_bus · d(1−d) · T ÷ L
相对平均值：    Δi_pp ÷ I = (1−d)·T·R ÷ L = (1−d)·T ÷ τ_e
```

三件事一次说清了。**纹波最大的位置是 d = 0.5**（因为 d(1−d) 在那里取极值，本章上面说的就是它）；
**相对误差的上界是 T ÷ τ_e**（d 趋 0 时取到，因为那时 (1−d) ≈ 1）；
所以要让纹波在任何占空比下都不超过平均电流的 10%，就必须 **T ≤ τ_e ÷ 10**——
这条判据的全部内容就是“最坏那一格也不超过 10%”，不是什么行业默契。

*（顺带解释了一个常见误解：纹波电压摆幅与相对纹波不是一回事。绝对纹波在 d = 0.5 最大，
相对纹波却在 d 小的**低速**轻载区最大（d 小对应反电势小，也就是转速低——别跑到额定转速去找最坏相对纹波）。工程上真正疼的是前者——它决定损耗和噪声；
判据里用的却是后者，因为它决定“平均”这个说法成不成立。）*

（这是本书给的一阶判据 [算]，不是任何厂商的规格。）

纹波本身可以算出来：

```text
Δi ≈ V · d(1−d) / (L · f_sw)
```

**它在 d = 0.5 时最大**（因为 d(1−d) 在 0.5 取极值）。这条有个立刻可用的推论：**你的电流最脏的时刻，是输出电压用了一半母线电压的时候**，也就是转速跑到一半附近。

现在看第 08 章那个结论的另一面。**先把口径钉住**：下面把斩波当一阶 buck 算，`d = 1` 意味着反电势等于母线电压——这颗电机在母线上根本转不到那么快，所以这个 d 是**模型读数**，不是三相桥的物理占空比（真实桥臂占空比每个电周期两次过 0.5，与转速无关；第 08 章说的 12.78 V 是 13.86 V 那一档的 92%，两处的分母不同）。在这个前提下：M8010 反电势幅值在 30 rad/s 时是 12.78 V（第 08 章按幅值不变约定算的那个数），母线 24 V，所以正常工况下占空比就在 12.78 ÷ 24 ≈ 0.53 附近——\*\*几乎正压在 d = 0.5 那个纹波最大的点上\*\*。也就是说这颗电机在标称最高速附近运行时，恰好落在纹波较大的区间里。

（L 与 R 官方未公布 [未]，所以本书不能算出 Δi 的绝对值。但“d=0.5 附近最脏”这条与 L 无关，任何一台电机都成立。）

**关键的一点：纹波不产生平均扭矩。** 扭矩由 i_q 的**平均值**决定（第 04、05 章）。纹波只是在铜里发热、在铁芯里产生附加损耗、在声学上产生噪声。所以“提高开关频率让纹波变小”改善的是发热与噪声，**不是扭矩精度**。扭矩精度靠的是死区补偿与采样时刻（第 13 章）。

## 第二级：惯量是一个转速积分器

同样的逻辑再往下走一层。

```text
τ = J · dω/dt        ⇔        ω(t) = ω(0) + (1/J)∫τ dt
```

**转速是扭矩的时间积分。** 转子（连同减速器、连杆、负载折算到轴上的部分）有一个转动惯量 J，它让转速不可能在 50 微秒里改变多少。

定义机械时间常数（把扭矩与转速用 k_t、k_e 连起来，忽略阻尼）：

```text
τ_m = J · R / k_t²
```

（这是“给一个电压阶跃、转速到达稳态 63% 要多久”的一阶近似 [行]。）

代一个量级看看。M8010 转子侧 k_t = 0.10094 N·m/A。若转子侧惯量在 1e-5 kg·m² 量级（**这是本书假设的量级，官方未公布** [未]），R 取 **0.040 Ω**（全书统一口径；宇树两个数都没公布，本书把 0.040–0.050 Ω 当一条区间，第 36 章的热算保守地取上沿）——（第 08 章与 `code/tools/foc_check.py` 的 `R_JOINT_ASSUMED_OHM` 用的都是它）。**宇树从未公布任何一颗关节绕组的相电阻** [未]，所以 0.040 是本书的算例假设，不是厂商参数；上一版这一处写 0.05 Ω，与第 08 章和脚本不一致，已统一：

```text
τ_m ≈ 0.00001 × 0.040 ÷ 0.10094² = 0.000039 s（即 0.039 ms）
```

**先说一件事：上一版这一行写的是 4.9 ms，错了 100 倍**——真正跳掉的是 k_t² 的指数：0.10094² = 1.019 × 10⁻²，被当成 1.019 × 10⁻⁴ 去除，商正好大 100 倍（写成“10⁻⁵ ÷ 10⁻² 那一步跳位”是错的解释：那么算出来是 5 ms）。改完之后本章的结论不但没塌，反而更清楚，因为正确的读法是这样三条：

**一，裸转子其实和开关一样快。** 0.039 ms 与开关周期 0.05 ms 是**同一个数量级** [算]（0.049 是旧版按 R = 0.05 Ω 算的，统一到 0.040 后是 0.039）。所以“转子对浪花的感觉像万吨轮”这个比喻，对**不带负载的电机本体**根本不成立——它慢不下来，是别的东西让它慢的。

**二、这条式子是折算不变量，换侧救不回来。** 把 J 乘 i²、k_t 乘 i，分子分母一起乘 i²：0.00001 × 6.33² × 0.040 ÷ (0.10094 × 6.33)² = **还是 0.000039 s** [算]。想靠“折到输出轴”把 τ_m 变大是个常见错觉——减速比不会改变这个常数，它只是把同一份惯量搬到另一格里记账。

**三、毫秒级来自负载，不来自转子。** 拿一颗“速比 22.5、转子常数仍取 M8010 那 0.10094”的关节代（**这是拼接：N7520-22.5 自己的转子侧 k_t 官方未公布** [未]；若改用它的 139 N·m ÷ 40 A = 3.475 当关节侧 k_t，下面两个数变成 0.083 ms 与 1.1 ms，差约 2.3 倍）：关节侧 k_t = 0.10094 × 22.5 = 2.271 N·m/A，把官方 `armature` = 0.0251 kg·m²（附录 C.2a 已证它是搬到输出轴的折算惯量 [厂]）当 J ⇒ τ_m = 0.0251 × 0.040 ÷ 2.271² = **0.19 ms**；再叠上小腿与大腿折算到膝的负载惯量（本书取 0.30 kg·m² 这一量级，官方未公布 [未]）⇒ (0.0251 + 0.30) × 0.040 ÷ 2.271² = **2.5 ms** [算]，1 ÷ τ_m = 397 rad/s ≈ **63 Hz**。**这才是“毫秒级”三个字的出处**：它是带负载的关节，不是电机。

于是本章那条级联判据的正确说法是：**开关 0.05 ms、电流环 τ_e 零点几 ms、空载转子 τ_m 0.039 ms、带负载的关节 τ_m 约 2.5 ms**——“机械比电慢一到两个数量级”这句话，只有在你把负载算进去之后才对。

两级加起来，这台电机的响应结构是：

```text
开关（0.05 ms）→ 电感积分（τ_e 零点几 ms）→ 电流
                → 惯量积分（空载 0.039 ms / 带负载约 2.5 ms）→ 转速
                                    → 再积分 → 角度（几十 ms 起）
```

**每一级都是一个积分器，两级串联，就把 20 kHz 的方波抹成了一个几乎平滑的转速——但这句话只在带负载时成立**：空载转子的 τ_m（0.039 ms）与开关周期同量级，从开关到 τ_e 也只有 4–10 倍而不是 10–100 倍。真正慢的那一级是负载惯量给的。 这就是“平均”合法的完整理由——不是近似技巧，是这台机器本身的物理结构。

## 那频率为什么不能无限高

因为第二笔账会来收钱。

```text
开关损耗 P_sw ≈ ½ · V · I · (t_rise + t_fall) · f_sw      ← 正比于 f_sw
导通损耗 P_on = I² · R_ds(on)                              ← 与 f_sw 无关
```

**提高 f_sw 让纹波变小（∝ 1/f_sw），但让开关损耗线性变大。** 两条曲线一交，就有一个最优点。这个点具体在哪，取决于器件的 t_r + t_f、母线电压、电流、以及你能带走多少热（第 36 章）。

机器人关节选 20 kHz 左右（行业常见量级 [行]；**宇树未公布任何一款关节的载波频率** [未]），除了电气考虑，还有一个非常不“物理”但非常真实的原因：

**20 kHz 刚好在人耳听觉上限之外。**

10 kHz 以下的 PWM 会让电机发出清晰的啸叫。一台 23 个关节的人形在安静的办公室里以 10 kHz 开关，听起来像一墙老式 CRT 显示器。这不是性能问题，是产品问题——但它是那种**会在评审会上被提出来、并且必须改的问题**。所以“为什么是 20 kHz 而不是 8 kHz”这个问题，一半答案是电气的，一半答案是市场部的。

## 一个立刻能用的推论：你能控制的最快的事，就是电流

两级低通还给出一个反向结论，它是第 12 章级联结构的地基：

**积分器不能对被积的东西做快的反应。** 电流环能跑 1–2 kHz，因为 τ_e 是零点几毫秒；速度环比电流环慢一到两个数量级，因为**带负载的关节** τ_m 约 2.5 ms（裸转子只有 0.039 ms，见上面那条更正——所以速度环慢的原因是负载，不是电机）。**注意不要把 1/τ_m 当成速度环的带宽**：1 ÷ 3.15 ms = 317 rad/s ≈ 50 Hz，那只是**开环植物极点**的位置；闭环带宽是增益决定的，可以高于它——**本书手上就有一个全是厂商数的一手例子**：官方训练仓库 mimic 配置给 `kp = 99.098`，官方 `armature = 0.025101925 kg·m²`（第 18、40 章引过）[厂]，那么这颗关节在位置刚度下的固有频率是

```text
ω_n = √(kp ÷ J) = √(99.098 ÷ 0.02510) = 62.8 rad/s ⇒ 10.0 Hz    [算]
想要临界阻尼，kd 应取 2√(kp·J) = 3.15 N·m·s/rad                [算]
```

**换掉 kp，ω_n 就跟着换，τ_m 一点没动**（官方那个 kd 是不是 3.15，本书未核到 [未]）。所以“τ_m = 3 ms”与“速度环跑一百多赫兹”从来不矛盾：**前者是植物的时间常数，后者是环路的工作点**；第 12 章那条 5–10 倍级联判据约束的是相邻两环闭环带宽之比，不是任何一环与 τ_m 的关系；位置环只能跑几十赫兹，因为连杆与负载更大。

所以当你想“让关节反应更快”，唯一有效的方向是**让电流变化更快**——提高 f_sw、减小 L（但 L 小纹波大）、提高母线电压（但器件耐压与绝缘要跟上）。**没有任何算法能让你绕过 τ_m。** 这条判据能帮你在选型会上省掉很多废话。

## 类比，以及它在哪儿破

类比：用一把脉冲式水枪推一辆水车。你每秒扣两千次扳机，水车只觉得有一股稳定的力在推它——因为水车的转动惯量把每一次冲击都摊平了。

**这个类比在哪里破两处**。第一，水车的阻力矩与转速无关，而电机的反电势**正比于转速**——所以“水车越转越难推”这件事在电机里是真实存在的，而且是第 08 章那个电压包络的全部来源。第二，水枪的脉冲不会让水车发出声音，而 PWM 会让电机啸叫——机械结构不但不完美积分，还会把某些频率放大（那就是第 22 章的结构模态）。

---

**一个可检验的说法**：PWM 斩波之所以不引起机械振动，是因为电流对电压、转速对扭矩构成两级串联积分器，其时间常数分别约为 τ_e = L/R（零点几毫秒量级）与 τ_m = J·R/k_t²（**裸转子 0.039 ms、带负载的关节约 2.5 ms**；本书上一版这一行写的 4.9 ms 是指数进位错，正文已更正）；带负载时机械那一档比开关周期慢约 50 倍（2.5 ms ÷ 0.05 ms），而 τ_m 是**折算不变量**、换到输出侧不会变大，所以“机械比电慢”的支撑是负载惯量而不是减速比；因此任何“让关节反应更快”的需求只能从电流环往上解决，不可能通过算法绕过 τ_m，也不可能靠换减速比绕过去。

**证据等级**：V = L·di/dt、τ = J·dω/dt、两级积分结构、纹波公式、开关损耗正比于频率，全部是电路与控制通识 [行]；τ_m 的三个值（裸转子 0.00001 × 0.040 ÷ 0.10094² = 0.000039 s（即 0.039 ms）、只算官方 `armature` 的 0.19 ms、叠上 0.30 kg·m² 负载的 2.5 ms）是 [算]，其中**转子 J、R 与那条 0.30 kg·m² 的负载惯量都是本书假设的量级，官方未公布** [未]（`armature` = 0.025101925 kg·m² 那一档取自官方训练仓库 [厂]），所以它们只能当“数量级感觉”用，不能当 M8010 或 G1 膝关节的参数引用；**上一版本节把第一个值印成 4.9 ms，是 k_t² 的指数被当成 10⁻⁴，已在正文连同两条自查一起更正**；20 kHz 是行业量级 [行]，宇树未公布 [未]；“d = 0.5 时纹波最大”与“反电势 12.78 V ⇒ 正常工况 d ≈ 0.53”是 [算]。

**可核对清单**：

- [ ] 自己代一次 τ_m：先拿你手边任何一颗**电机本体**的 J、R、k_t——多半落在**几十微秒**而不是毫秒；再把你要驱动的那块惯量加进 J，看它什么时候才升到毫秒级。做完这一格你就知道“机械比电慢”到底慢在谁身上，而不在减速比身上
- [ ] 用 Δi ∝ 1/f_sw 与 P_sw ∝ f_sw 画两条线，标出它们的交点，那就是你能选的最高频率
- [ ] 找一段 8–12 kHz 的 BLDC 驱动音频（开源社区有），亲耳听一下“为什么是 20 kHz”
- [ ] 在宇树电机页面搜“switching frequency / 载波 / PWM 频率 / 电感 / 相电阻 / 转动惯量”，确认这六项是否全部查不到（预期：是）
