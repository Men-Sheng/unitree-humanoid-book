# 一台 G1 的钱花在哪：23 个关节、35 kg、8.5 万元

## 先把最贵的那一件事说清

宇树 G1，1.32 米，35 公斤，23 个自由度，官方起售价 8.5 万元人民币 / 13,500 美元 [厂]。

现在做一件出版社可能会希望我们别做的事：**猜它值多少成本。**

必须先把话说在前面：宇树从未公布任何一款产品的成本。下面这两个数是第三方估算——中邮证券的拆解口径约 **¥41,574**（对应整机毛利约 40.7%），SemiAnalysis 对进阶版的口径是 **$9,976 成本 vs $27,300 零售**（毛利 67%）[拆]。两个数都不可当事实引用，本书只取它们的**共同结论**：

> **一台 G1 的器件成本大约四万元人民币量级，售价是它的两倍上下。**

四万元要买 23 个能精确出力矩的关节、一套感知、一块大脑、一块电池、一具骨架、以及把它们缝在一起的线缆与结构件。这笔账最有信息量的地方，是它的分配比例。

> [!QUOTE]
>
> 最核心的是从设计阶段就把成本降下来，比如零部件的数量尽可能少、每个零部件适合开模、模具成本尽可能低、装配时对公差的容忍度要高……
>
> 王兴兴 — 上海证券报（同上，来源 A），谈降价靠什么 — 2026-08-19（直接引语）

## 先把这两个第三方数各自验一遍

拿自己的除法查一遍它们，比引用它们有用得多。

中邮证券给了两个数：BOM 约 41,574 元，毛利约 40.7%。这两个数自己就能反解出它心里那台机器的售价：

```
1 − 0.407 = 0.593          （中邮口径自己给的毛利率 40.7%）
售价 = 41,574 ÷ 0.593 = 70,108 元
```

可官方起售价是 85,000 元。也就是说那份 40.7% 不是对着 8.5 万算的，是对着约 7.0 万算的。差的 1.5 万是什么——含税、渠道、还是更早的定价——本书查不到，写 [未]，也不拿它去修正谁。

SemiAnalysis 那两个数也能自己除：

```
9,976 ÷ 27,300 = 0.3654
毛利率 = 1 − 0.3654 = 63.4%     （报道口径写的是 67%）
```

差 3.6 个百分点。而它引用的那个 27,300 美元，在宇树商城里也没有对应格子：商城在架的是 G1 13,500 美元与 G1 Pro 21,500 美元，且官方注明 “Tax and Shipping cost excluded” [厂]。**三条口径（8.5 万 / 约 7.0 万 / 27,300 美元）本书全部并列，不取平均、不择一。**

这不是说拆解报告不可信。恰恰相反——**能被读者自己拆出内部不一致的估算才是可以用的估算**，因为你能核对它。但是要把它的边界写死：这些数是拆解与券商口径，**宇树从未公布过任何一款产品的成本**，所以下面所有除法只在“数量级”这一层成立；把某一份 BOM 当成厂商口径去做采购或竞品分析，是做不到、也不该做的事。

## 关节模组的单价：一条能自己走完的链

行业通行的结构是**执行器占整机 BOM 的 40–60%** [行]。把这条区间分别按到两个第三方总数上：

```
中邮口径关节那一档下限 = 41,574 × 0.40 = 16,630 元；上限 = 41,574 × 0.60 = 24,944 元
再除以颗数：16,630 ÷ 23 = 723 元/颗；24,944 ÷ 23 = 1,085 元/颗
SemiAnalysis 口径下限 = 9,976 × 0.40 = 3,990 美元；上限 = 9,976 × 0.60 = 5,986 美元
再除以颗数：3,990 ÷ 23 = 173 美元/颗；5,986 ÷ 23 = 260 美元/颗
```

两条链不同币种，本书**不做汇率换算**，让它们各自成立。

但“颗”这个单位在这里是靠不住的：一个 5 N·m 的腕关节和一个 139 N·m 的膝关节根本不是一件东西。官方 URDF `g1_23dof_rev_1_0.urdf` 把 23 颗关节的 `effort` 分成四组：139 N·m 四颗（两个髋侧摆 + 两个膝）、88 五颗、35 四颗（踝）、25 十颗（肩肘腕滚）[厂]：

```
扭矩总量 = 139×4 + 88×5 + 35×4 + 25×10 = 1,386 N·m     （四组分别是 556、440、140、250）
平均 = 1,386 ÷ 23 = 60.3 N·m/颗
每牛米单价下限 = 723 ÷ 60.3 = 12.0 元/(N·m)；上限 = 1,085 ÷ 60.3 = 18.0 元/(N·m)
美元口径下限 = 173 ÷ 60.3 = 2.87 美元/(N·m)，本书取 2.9；上限 = 260 ÷ 60.3 = 4.31，取 4.3
```

现在可以拿宇树唯一挂过价的那颗关节来对表。GO-M8010-6：369 美元、23.7 N·m [厂]：

```
宇树零售单价 = 369 ÷ 23.7 = 15.6 美元/(N·m)
倍数 = 15.6 ÷ 4.3 = 3.6 倍；15.6 ÷ 2.9 = 5.4 倍
```

**宇树自己单卖一颗关节的“每牛米美元价”，是拆解口径下 G1 内部关节价的 3.6–5.4 倍。** 这个差有两个来源，而手头这些数分不开它们：一是零售价含渠道与毛利、拆解口径是器件成本；二是大关节天生每牛米更便宜——同样的壳、同样的驱动板、同样的轴承，磁钢和齿轮的体积却在涨，而扭矩涨得比体积快（第 02 章那条 τ ∝ L⁴ 与质量 ∝ L³ 的差，落到钱上就是每牛米的单价随尺寸下降）。**本书不挑一个说法，只把除法摆在这里。**

## 减一减，看这条链闭不闭合

拆解口径里少见的两行是感知与算力的具体金额：感知阵列 < $600、算力模块 ≈ $750 [拆]。把它们从 SemiAnalysis 的总成本里减掉：

```
关节占成本 = 9,976 − (600 + 750) = 8,626 美元     （除感知、算力之外的一切）
关节占比下限 = 3,990 ÷ 8,626 = 46%；上限 = 5,986 ÷ 8,626 = 69%
剩下的下限 = 8,626 − 5,986 = 2,640 美元；上限 = 8,626 − 3,990 = 4,636 美元
```

那 2,640–4,636 美元要买：13 串 9000 mAh 电池（官方规格 [厂]，换算约 0.43 kWh）、铸铝与机加结构、全套走线、装配工时，以及头颈那两块显示。**这就是这条链闭合的样子**：减掉已知的两块，关节加电池加结构刚好填满剩下的格子，塞不下第二个大件。“关节占一半”最硬的证据不是那个 40–60% 的引用，而是这个减法之后没有别人的位置。

## 数量是乘数：一颗关节的钱怎么变成一整台机器的钱

宇树公开定价的唯一一颗一体化关节 GO-M8010-6 单卖 **369 美元** [厂]。裸乘一次：

```
裸乘零售价 = 23 × 369 = 8,487 美元 ÷ 13,500 = 62.9%     （全是零售价，含毛利）
假设自产摊薄一半 = 23 × 369 ÷ 2 = 4,244 美元            （本书的假设，不是数据）
```

上一版本书把这条乘积叫“上界”，这里更正：369 美元那颗既是最老的型号、又是**最小的档位**（23.7 N·m 对 G1 的 60.3 N·m 平均），含毛利往上抬、含档位往下压，两个方向同时成立，所以它不是界，只是一个粗略的乘积。

但这个近似在另一件事上是硬的，而且不依赖任何假设：

```
关节单价每降 100 元 ⇒ 整机降幅 = 100 × 23 = 2,300 元
关节每颗减重 50 g ⇒ 整机减重 = 50 × 23 = 1,150 g = 1.15 kg（占 35 kg 的 3.3%）
每颗扭矩多 1 N·m ⇒ 整机多 = 1 × 23 = 23 N·m（膝 90 → 113 N·m，+26%）
```

**数量是乘数。** 这就是为什么“把一颗关节做到 530 克、369 美元”这件事，比“把一台机器人做得更聪明”更能决定一家公司的毛利。

那为什么一颗关节要 723–1,085 元？往下追一层：因为它不是一台电机，它是**四合一**——无框永磁电机 + 减速器 + 两套编码器 + FOC 驱动板，装进一个要密封、要让线缆从中心孔穿过、还要撑住交叉滚子轴承的壳里（官方对关节的措辞就是这四件；轴承与 “Full Joint Hollow Electrical Routing” 写在 G1 页 [厂]）。

那这四件合在一起又靠什么？靠三道彼此不共享供应链的精密工序——绕线与磁钢装配、齿轮加工与热处理、编码器对零与**标定**——再加上缝进一个壳之后的逐颗跑合测试。齿轮厂做不了绕组，驱动器厂做不了齿形，良品率与工时这两样都长在一家公司自己的产线上，而产线买不来。**这才是“关节能自己做、手做不了”的技术内容**，第 25 章会在一只 45 克的指关节上再遇到它一次。

这条“关节占一半”什么时候失效？两种场合。一是把灵巧手算进来：手也是执行器，G1 EDU 那 7 + 2 个手部自由度若按外购价计，执行器占比就不在 40–60% 这个带里，而是往上顶（下一节 14,215 元/只就是证据）。二是换一台机器：H2 有 31 颗关节、R1 官方两处口径给 20 与 26（本书并列），颗数一变乘数就变，而占比未必变。**所以这条规律的内容是“单件 × 数量”，不是“一半”这个数字本身。**

第 1 部花十章讲一颗关节，理由就在这里：**那颗东西是这台机器的成本中心、重量中心、可靠性中心，也是所有上层算法的物理边界。**

## 那“便宜”到底是怎么来的

8.5 万元一台双足人形，在 2023 年这个价买不到一条腿。便宜不是单点魔法，是三类器件在同一个时间窗内同时降价的乘积。

**一，关节电机。** 行业报道的口径是：进口同规格力矩电机曾要 5–6 万元，国产同类降到 500–600 元量级 [推]。宇树的路子更彻底——**自研自产**，并且把 GO-M8010-6 这类关节当元器件单卖（369 美元，官方店铺在架 [厂]）。当一家整机厂同时是器件供应商，它的关节成本就是自己的出厂价，不是别人的零售价。

**二，减速器。** 谐波减速器曾长期被日本哈默纳科主导，报道口径是进口 2000–3000 元、国产 1500–2000 元 [推]。**但这里必须给本书最重要的一个诚实声明**：在宇树自己的产品上，“用了国产谐波减速器”这句话**证据不足**。官方明确说“谐波减速器、减速比 60+、背隙 6 弧分”的只有 Z1 机械臂 [厂]；G1 的减速方案来自第三方拆解，口径是**两级行星、总速比约 20.58** [拆]，与官方 `unitree_rl_lab` 配置里型号名自带的 14.3 / 22.5 不一致（本书两条都列，见第 14 章）。**“宇树靠国产谐波降本”是一个流传很广但没有一手支撑的说法，本书不采用。**

**三，感知。** 这一条宇树公布得最清楚，因为它就是它的产品：

|---|---|---|

L1 那颗 ¥999 的雷达是关键证据：**宇树把感知也做成了自己的元器件**。而灵巧手是另一回事——2025 年前三季度宇树向外采买了 1,210 只因时的手、金额 1,720 万元，占其外采的 96% [推]。**手，是它目前唯一没能自研摊薄的大件。** 除一下才知道“最贵”到什么程度：

```
一只手 = 1,720 万元 ÷ 1,210 只 = 1.4215 万元/只        （采购均价；输入是 [推] 口径的两个数）
换算成元：1.4215 万元 就是 14,215 元/只
折成关节 = 14,215 ÷ 904 = 15.7 颗     （904 是关节单价区间 723–1,085 的中点）
一整条腿 = 12 颗 × 904 = 10,848 元，比一只手便宜     （12 颗加起来还不到一只手的钱）
```

区间中点只是本书为了给你一条能核对的算式，不代表厂商成本。但结论对这个中点不敏感：把 723 与 1,085 两个端点各代一遍，“一只手折 13 到 20 颗关节”、“一只手贵过一条腿”这两句话都成立。两只手装上去，14,215 × 2 ÷ 85,000 = 33.4%，光外采的手就吃掉售价的三分之一——这就是为什么在官方配置表里手一直是选配 [厂]。

## 拆开看：一台 G1 的五个成本块

把上面这些拼成一张结构图（比例取行业通行区间 + 拆解口径，**全部标注为估算**）：

```
① 23 个关节模组（电机+减速器+编码器+驱动板+轴承+密封）   ~50%   [行][拆]
② 感知（雷达 + 深度相机 + IMU + 触觉）                  <$600  [拆]
③ 算力（Orin NX 16GB 模组 ¥5,499 量级）                 ≈$750  [拆]
④ 能源（13 串 9000 mAh + BMS + 充放电保护）              —      [未]
⑤ 结构（铸铝/机加/工程塑料 + 线缆 + 装配）               —      [未]
```

②③ 那两行是拆解报告里少见的给出了具体金额的项 [拆]。把它们和 8.5 万的售价放在一起看，会得到一个反直觉的结论：

```
感知加算力 = 600 + 750 = 1,350 美元
占整机售价 = 1,350 ÷ 13,500 = 10.0%
占器件成本 = 1,350 ÷ 9,976 = 13.5%
```

**感知 + 算力加起来约等于整机售价的 10%。**

也就是说，**这台机器“聪明的部分”很便宜，“会动的部分”很贵。** 一个想把人形做便宜的公司，必须去啃关节；一个想把人形做聪明的公司，必须先有人把关节做便宜。这两句话描述了当下行业里两种完全不同的商业策略（第 39 章会展开）。

## 毛利那条线：60.13% 说的是哪一台机器

公开信息里有一组对理解整本书都很重要的数：宇树 2025 年营业收入 **17 亿元**、综合毛利率 **60.13%**、人形机器人占营收的比例从 2024 年的 **27.68%** 升到 2025 年的 **51.78%** [查]（《宇树科技 IPO 在即 420 亿发行估值、60% 毛利率冲刺上市》，新浪，2026-08-02，https://k.sina.com.cn/article_7879996653_1d5af34ed02001kkd0.html；本书 2026-10-08 回原页逐段读过）。同一条报道给的另两个毛利率是 2023 年 44.22% 与 2024 年 56.74% [查]（同上）——**毛利率是三年一年一台阶涨上来的，不是天生如此**。

先把 51.78% 这个数的边界划清，因为它经常被混着用：**51.78% 是份额**，说的是人形这一类产品在宇树全部收入里占了多少；**它不是客户构成**——“人形那部分收入里，科研教育这样的客户占多少”是另一个量、另一张表，本书没有把它核到一手，所以正文不写那个数，只提醒两个量不许互相替换。

## 一条被删掉的除法：两个“超过”为什么不能相除

上一版这一节还写了第三个数——“扣非净利超过 6 亿元”——并拿它做了一次减法（毛利率 60.13% 减净利率 35.3%，得 24.8 个百分点）。这一版**两句都删了**。两条理由，第二条比第一条重要。

**一、那句“扣非净利超过 6 亿元”没核到原文。** 本书 2026-10-08 回到上面那条 [查] 链接的原页读过：报道写 2025 年利润时用的不是这个说法，全文也搜不到“扣非净利超过 6 亿”这句话；交易所文件与招股书原文本书没有读到，所以它连一个能接上的二手出处都没有。**查不到出处的数不进正文，由它派生的数一起删。** 本书不许的做法是把这个数留在原地、前面加一个“约”字蒙过去。

**二、就算那句成立，那个除法也不成立。** 为什么不成立？因为“营收超过 17 亿”与“扣非净利超过 6 亿”都是**下界**：各自只说“至少多少”，没有一个说“是多少”。两个下界相除，得到的既不是净利率，也不是净利率的界：

| 假设的真实值 | 净利 | 营收 | 相除会得到 |
|---|---|---|---|
| 上一版代进去的那一对 | 6 亿 | 17 亿 | 35.3% |
| 营收再大一截 | 6 亿 | 60 亿 | 10.0% |
| 净利大一截 | 60 亿 | 17 亿 | 353% |

三行用的都是同一对“超过”，结果从 10% 跳到 353%。所以 35.3% 不是估算，是**把不等式当成了等式**；再拿它去减 60.13%，是在一个已经错的数上做第二步——那个“24.8 个百分点”从来没有存在过。

这才是本章真正要教的那件事：**看到一个数，先问它是点值还是界。** 产品页上的“峰值扭矩”是界（本书第 02 章整章都在用这个界，并且拒绝把它当工作点），“营收超过 17 亿”也是界；本书正文里的除法，只有分子与分母都是点值时才许做。毛利率 60.13% 与营收 17 亿元是报道里写死的两个点值 [查]，本书就只做点值能做的事——把它们和拆解口径的毛利率并排摆一摆；净利那一格本书没读到可以信的写法，所以那个减法到此为止，不做。

## 四条毛利率：它们不在同一件事上，本书不取平均

那 60.13% 能不能拿来算 G1 的器件成本？不能。把本章用过的几个毛利率并排摆开，就能看清为什么不能——这也是“冲突不抹平”这条纪律的示范：

| 口径 | 数 | 说的是什么 |
|---|---|---|
| 公司综合毛利率 60.13% [查] | 2025 年，全产品线 | 四足 + 人形 + 组件 + 雷达加在一起的毛利 |
| 中邮拆解口径 40.7% [拆] | 单款 G1，隐含售价约 7.0 万 | 一台人形的器件 BOM 对着它自己那档价 |
| SemiAnalysis 口径 63.4%（报道写 67%）[拆] | 进阶版 G1，27,300 美元 | 另一款配置、另一个价 |
| 官方起售价 85,000 元 [厂] | 基础版 G1 | 只有价，没有成本 |

**四个数并列，不合并、不平均、不“以最新为准”。** 它们的分母根本不是同一个东西：60.13% 是整家公司所有产品的毛利率，40.7% 与 63.4% 是一款人形的器件成本除法。一个人如果拿 60.13% 去推 G1 的器件成本，他其实是在假设这台人形的毛利等于公司平均毛利——而 2025 年人形才刚占到营收的一半（51.78% [查]），剩下那将近一半是四足、关节组件与雷达，它们的毛利结构跟一台双足不是一回事 [推]。**这一句是本章能给的最实用的提醒：财务数与器件数之间没有免费的换算。**

再看那笔募资的分配：**42 亿里有 20 亿投给模型，只有 11 亿投本体、6 亿投产能**（报道口径：科创板挂牌，发行价 150.80 元，募资约 42 亿元，其中 20.22 亿投向具身模型、11.1 亿投本体、6.24 亿投制造基地，规划年产 7.5 万台双足 + 11.5 万台轮式）[推]：

```
20.22 + 11.1 + 6.24 = 37.56 亿 ÷ 42 亿 = 89.4%
⇒ 报道口径里还有约 4.44 亿没有被这三项覆盖，本书不猜它是什么
```

（挂牌日期、发行价、这三个项目的分配比例与产能规划数，本书只读到二手转述，一律按 [推] 处理，与上面那几个 [查] 数不同级。）

一家靠本体毛利活着的公司，把一半的钱押在了大脑上。这个动作本身就是第 4 部存在的理由——它说明在宇树自己的判断里，**躯体的问题已经阶段性解决，数据与模型的问题还没有。**

而本书第 1 部讲的那 23 个关节，正是那 11 亿要继续优化的东西。

## 那颗东西贵在哪一格：关节成本往下压一分钱，整机毛利涨多少

把“数量是乘数”再往下追一层就能得到一句话：**整机毛利是关节成本的杠杆，杠杆倍数约等于关节在 BOM 里的占比。** 用两个第三方口径各算一遍“关节成本降 10%”（本书取 50% 这个区间中点，只为给一条可核的算式）：

```
中邮口径，关节那一档 = 41,574 × 0.5 = 20,787 元；降一成的量 = 20,787 × 0.10 = 2,079 元
新器件成本 = 41,574 − 2,079 = 39,495 元
对官方起售价，老毛利 = 1 − 41,574 ÷ 85,000 = 51.1%；新毛利 = 1 − 39,495 ÷ 85,000 = 53.5%   ⇒ +2.4 个百分点
对中邮自己的隐含售价，老毛利 = 1 − 41,574 ÷ 70,108 = 40.7%；新毛利 = 1 − 39,495 ÷ 70,108 = 43.7%   ⇒ +3.0
SemiAnalysis 口径，关节那一档 = 9,976 × 0.5 = 4,988 美元；降一成 = 4,988 × 0.10 = 499 美元；新成本 = 9,976 − 499 = 9,477 美元
对报道里那个零售价，老毛利 = 1 − 9,976 ÷ 27,300 = 63.4%；新毛利 = 1 − 9,477 ÷ 27,300 = 65.3%   ⇒ +1.9
```

一颗关节降一成，整机器件成本降 5%，毛利率涨 1.9 到 3.0 个百分点。反过来读更实用：**任何“把整机做便宜 10%”的方案，如果不能落到那 23 颗东西上，它就必然去吃毛利率。**

## 产能那一格：18 秒一颗关节

规划年产后，“关节是瓶颈”从形容词变成一个数：

```
双足关节年需求 = 7.5 × 23 = 172.5 万颗/年     （轮式那 11.5 万台不在本章这条链里）
一年的秒数 = 365 × 24 × 3600 = 31,536,000 秒
节拍 = 31,536,000 ÷ 1,725,000 = 18.3 秒/颗        （日产量 = 1,725,000 ÷ 365 = 4,726 颗/天）
整机节拍 = 18.3 × 23 = 421 秒 ⇒ 每 7 分钟下线一台
```

（[算]，输入为 [推] 的产能规划数与 [厂] 的自由度。）

18.3 秒里要装完绕线、磁钢、齿轮、轴承、两套编码器，还要跑完对零、标定和逐颗测试——这还只是节拍，不是良率。今天实际是几秒一颗、良率多少，官方未公布 [未]。但这条算式的价值不在于它答了什么，而在于它给了你一个**可以拿去问厂商的具体问题**；一家规划年产 7.5 万台 × 23 颗 = 172.5 万颗精密一体化关节的公司，它的标定工位在哪里。

## 类比，以及它在哪儿破

类比：一台人形机器人的成本结构像一间餐厅——食材（关节）占一半，装修（结构）与餐具（感知）都不贵，而“主厨的创意”（模型）几乎不要钱，因为它是别人开源的。

**这个类比在哪里破**：餐厅的食材成本随营业额线性涨，而关节成本**不随销量线性降**——它受限于铜、稀土磁钢、精密齿轮的加工产能，而那三样的产能本节上面只算到了节拍、没算到良率。所以“卖得多就更便宜”这条在软件上成立、在关节上会撞上一堵物理墙；墙的另一面是热，第 36 章整章在讲它把“持续出力”压回多少。
