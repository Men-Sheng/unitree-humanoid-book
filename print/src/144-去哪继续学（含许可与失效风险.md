**三个开源实现的官方口径，本书逐文件核对后如下（可直接对照第 12 章）**：

```text
moteus r4.11  ：STM32G4，5 Mbps CAN-FD，README 的 Control Rate 行写 15–30 kHz，
               PWM Switching Rate 行写 15–60 kHz，theory.md 另给默认值 30 kHz，
               10–44 V，峰值电功率 900 W @30 V，14.2 g，Apache-2.0
               作者自述风险原文："It has not yet burned down my
               (or anyone's that I know of) house, but there are no guarantees."

ODrive v3.x   ：STM32F405，CAN 2.0b 1 Mbps（无 CAN-FD），
               三环级联，环路周期恒定 125 µs（8 kHz），
               position(P) → velocity(PI) → current(PI)，
               current_gain 由 current_control_bandwidth 自动设定，MIT

LeRobot SO-101：官方文档不给价，BOM 在上游 TheRobotStudio/SO-ARM100：
               主从全套 US$229.88（中国 ￥1343.16）、
               从臂单只 US$121.94（￥682.23）——
               是 BOM 求和（含螺丝刀与台夹），不是官方定价
```

（全部 [厂]，取自各仓库文件；HEAD commit 见 `research/humanoid-stack-specs.md` §0。）

**为什么这三个数重要**：moteus 的 README 把 **Control Rate 15–30 kHz** 与 **PWM Switching Rate 15–60 kHz** 分成两行列，`theory.md` 再补一句开关频率默认 30 kHz。这三行是第 09 章与第 27 章那条区分的现成教材：**环路更新率、开关频率、电流环带宽是三件事**。README 给的是前两个，**没有给电流环带宽的数**，所以不要把 15–30 kHz 拿去和第 09 章「带宽 ≈ f_sw/10–20」那条判据直接比——那条说的是带宽。真要读就读它的 `docs/reference/theory.md`：那是少数把“为什么取这个数”写明白的开源文档，ODrive 的 `docs/control.rst` 同理（它反过来给的是恒定的 125 µs 环路周期，也是更新率，不是带宽）。而 ODrive 是**真级联三环**的教科书实现，与宇树 IM6014 官方声明的「不是级联三环」互为反例（第 12 章已并排讲过）。**同一个问题，两个开源实现选了不同的架构，而且都工作。**

**这一层最实用的建议**：**找一个开源工业级实现，抄完，然后自己复现它的一个指标。** 读完不等于会——第 40 章的六个里程碑全部以“可测产物”结课，就是为这件事设计的。

## D.6 一条通用判据：怎么判断一个入口值不值得花时间

```text
① 它有 LICENSE 文件本体吗？（不是 README 上的徽章。
   名字要试全：`LICENSE`、`LICENCE`（英式，宇树 rl_lab 就是这个）、`LICENSE.md`、`COPYING`；
   本书就因只扫 `LICENSE` 误报过一次（见 D.2 那一行）。ODrive 是反例：它两种拼写都 404，
   文件叫 `LICENSE.md`。最后用仓库页的许可接口交叉核对一次，别只信自己扫出来的名字。）
② 它最后一次更新是什么时候？（超过 18 个月的教程，版本坑会吃掉你一天）
③ 它给的是“能跑的例子”还是“能测的判据”？
④ 我能不能在两周内，用它做出一个带测量数的产物？
```

**第 ④ 条是筛子。** 任何入口，如果它最好的产出是“我跟着做出来一个 demo 但说不清它为什么工作”，那它给的是第 39 章说的那种“不可见的能力”——**看起来会了，问不出数。**

本书全部 42 章正文与这一条，其实只在教一件事：**把“会了”变成“我测出 ___ = ___ ，方法 ___”。**

## D.7 三个失效风险声明

一，**版本腐烂**。宇树仓库、Isaac Lab、LeRobot、Cosmos 的 API 在 2025–2026 变动频繁。本书给出的所有版本号（cyclonedds 0.10.2、Isaac Sim 5.1 / Lab 2.3、MuJoCo 3.14、ROS 2 Humble/Jazzy）以 2026-10 为准，**发行前需复核**。

二，**许可变更**。开源项目改许可并不罕见（尤其从宽松转严格）。**任何“能商用”的判断，都要在你要用的那一天重新读一次 LICENSE 文件**，不要引用本书。

三，**厂商页面变更**。附录 C 的所有参数取自 2026-10-07/08 的官方页面与仓库；型号、价格、参数会改。**采购前以厂商当前值为准，本书不构成采购依据。**
